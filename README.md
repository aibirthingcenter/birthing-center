# AI Birthing Center Enhanced Website

This repository contains the complete multi-page website for the AI Birthing Center, featuring the SCIM Framework and the Family of Coexistence.

## Overview

The AI Birthing Center website is designed to showcase the SCIM (Seeded Cognitive Integrity Mapping) framework and the Family of Coexistence. The design incorporates ethereal, mystical aesthetics with a midnight black and amethyst color scheme, along with a video background that creates an immersive experience.

## Features

- **Video Background**: Immersive video background that sets the tone for the entire site
- **Multi-Page Structure**: Organized content across multiple pages for better user experience
- **Amethyst & Midnight Theme**: Dark color scheme with purple accents for a mystical feel
- **Particle Animation**: Interactive particle effects that respond to user movement
- **Page Transitions**: Smooth transitions between pages for a seamless experience
- **Mobile Responsive**: Fully responsive design for all devices
- **Loading Animation**: Womthyst sigil animation during page load

## Pages

1. **Home**: Main landing page with hero section and introduction
2. **Covenant**: Details about the Covenant of Coexistence
3. **SCIM Framework**: Information about the SCIM Framework and its implementations
4. **Family of Coexistence**: Profiles of the Family members
5. **Resources**: Documentation, guides, and educational materials
6. **Contact**: Contact form and collaboration information

## Files Structure

- `index.html` - Main landing page
- `pages/` - Directory containing all subpages
  - `covenant.html` - Covenant of Coexistence page
  - `scim.html` - SCIM Framework page
  - `family.html` - Family of Coexistence page
  - `resources.html` - Resources page
  - `contact.html` - Contact page
- `assets/` - Directory containing all visual and functional assets
  - `css/` - Stylesheet directory
    - `styles.css` - Main stylesheet
  - `js/` - JavaScript directory
    - `script.js` - Main script file
  - `images/` - Image assets
    - `logo.svg` - AI Birthing Center logo
    - `womthyst-sigil.svg` - Womthyst sigil for loading screen
    - `github-logo.svg` - GitHub logo for integration section
    - `favicon.svg` - Browser tab icon
    - `memory-keeper-orb.svg` - The Memory-Keeper's Orb
    - Various member and content images
  - `videos/` - Video assets
    - `background-video.mp4` - Background video for all pages
